# แชทบอทส่วนตัวใน LINE 💬

แชทบอทที่คุยแบบตัวต่อตัวใน LINE Official Account — เจ้าของเขียนคำสั่งเองว่าให้บอทเป็นใคร รู้ข้อมูลอะไร ตอบแบบไหน แล้วบอทจะคุยตามนั้น ใช้เป็น **เลขาส่วนตัว** หรือ **แอดมินตอบลูกค้า** ก็ได้

👉 **เพิ่งได้ไฟล์มา เริ่มที่ [INSTALL.md](INSTALL.md)** — คู่มือติดตั้งทีละขั้นตั้งแต่ตั้งชื่อบอทจนแอดเพื่อนแล้วคุยได้จริง

---

## ทำอะไรได้บ้าง

- **ทำหน้าที่ตามคำสั่งของเจ้าของ** — เขียนในไฟล์ `brief.txt` ว่าบอทคือใคร รู้ข้อมูลอะไร (สินค้า ราคา เวลาเปิด นโยบาย) ตอบแบบไหน ห้ามทำอะไร ข้อมูลที่ไม่ได้เขียนไว้ บอทจะไม่เดา
- **จำบทสนทนาของแต่ละคน** — คุยต่อจากเมื่อกี้ได้ พิมพ์ "สรุปที่คุยกันวันนี้" ก็สรุปให้
- **อ่านทุกอย่างที่ส่งมา** แล้วคุยต่อจากนั้น
  - 🖼️ รูป → อ่านข้อความ/ตัวเลขในรูป (สลิป เอกสาร ฉลาก แชทแคป)
  - 🎤 ข้อความเสียง → ถอดเป็นข้อความแล้วตอบ
  - 🎬 วิดีโอ → ดูเฟรมแรก
  - 📄 ไฟล์ txt/csv/json/md/pdf → อ่าน 2,000 ตัวอักษรแรก
  - 😺 สติกเกอร์ · 📍 ตำแหน่ง → รู้ว่าส่งอะไรมา
- **ทักทายเองตอนมีคนแอดเพื่อน** (ตั้งข้อความเองได้)
- **ตั้งชื่อบอทเองได้** — ชื่อ คำแทนตัว คำลงท้าย ค่ะ/ครับ ตั้งใน `.env`
- คนกดยกเลิกข้อความ (unsend) → บอทลืมข้อความนั้นตาม

**คุยได้เฉพาะแชทส่วนตัว** — ถ้ามีคนเชิญเข้ากลุ่ม บอทจะบอกสั้นๆ แล้วออกจากกลุ่มเอง

---

## สั่งหน้าที่บอท

เขียนไฟล์ `brief.txt` ข้างๆ `package.json` (ตัวอย่างใน [`brief.example.txt`](brief.example.txt) มีทั้งแบบร้านค้าและแบบเลขาส่วนตัว)

```text
คุณคือแอดมินร้านคุกกี้ "บ้านมะลิ" ตอบลูกค้าที่ทักมาในแชทส่วนตัว
ข้อมูลร้าน:
- คุกกี้เนยสด กล่องละ 120 บาท · ส่งฟรีเมื่อซื้อ 3 กล่องขึ้นไป
วิธีตอบ:
- ลูกค้าบอกจำนวนกล่อง ให้คิดยอดรวมพร้อมค่าส่งให้เลย
ห้าม:
- ห้ามลดราคาเอง เรื่องที่ไม่มีในนี้ให้บอกว่าจะให้เจ้าของร้านติดต่อกลับ
```

- บรรทัดที่ขึ้นต้น `#` คือหมายเหตุ ไม่ส่งให้ AI
- ยาวได้ไม่เกิน 8,000 ตัวอักษร — ยิ่งยาว ค่า AI ต่อข้อความยิ่งสูง
- คนที่แชทเข้ามาเปลี่ยนหน้าที่บอทไม่ได้ เปลี่ยนได้ที่ไฟล์นี้เท่านั้น แก้แล้วต้องอัปโหลดขึ้นคลาวด์ใหม่ (ดู INSTALL.md)
- ลองคุยกับบอทใน Terminal ก่อนผูก LINE ได้ด้วย `npm run chat`

## ข้อจำกัด

- บอทคุยได้อย่างเดียว ทำงานนอกแชทเองไม่ได้ (ยืนยันออเดอร์ ตัดสต็อก ลงนัด โอนเงิน)
- บอทเห็นเฉพาะแชทของตัวเอง — แต่ละคนที่คุยด้วยมีความจำแยกกัน
- จำบทสนทนาย้อนหลังได้ราว 6,000 ตัวอักษรล่าสุดของแต่ละคน
- ทักไปหาคนเองไม่ได้ ตอบเมื่อมีคนทักมาเท่านั้น

## ต้นทุน

| รายการ | ค่าใช้จ่าย |
|---|---|
| ตอบแชท 1 ข้อความ | ~฿0.05–0.15 (ขึ้นกับความยาวของ brief.txt และบทสนทนา) |
| อ่านรูป เสียง วิดีโอ | +~฿0.04–0.1 ต่อชิ้น |
| ส่งข้อความกลับใน LINE | ฟรี (ตอบกลับด้วย reply) |
| ที่รันบอท (Railway) | ~$5 ต่อเดือน |

กันค่า AI บานด้วย `DAILY_LIMIT` — จำนวนข้อความสูงสุดต่อคนต่อวัน (ค่าเริ่มต้น 100, `0` = ไม่จำกัด)
ค่าเริ่มต้นใช้ `google/gemini-2.5-flash` ผ่าน OpenRouter (ถูกและเร็ว) เปลี่ยนได้ที่ `AI_MODEL` / `VISION_MODEL`

## ทดสอบ

```bash
npm install
npm test        # เทส offline ไม่ต้องต่อเน็ต — ต้องขึ้น "0 พัง"
npm run chat    # คุยกับบอทใน Terminal (ต้องมี OPENROUTER_API_KEY ใน .env)
```

## โครงสร้างโค้ด

```
src/index.js      webhook + /health + /admin/backup + จุดเริ่มโปรแกรม
src/bot.js        รับ event จาก LINE: ทักทาย / ตอบแชท / อ่านสื่อ / ออกจากกลุ่ม / unsend / เพดานต่อวัน
src/ai.js         เรียก AI ผ่าน OpenRouter + ประกอบ prompt กับความจำบทสนทนา
src/brief.js      อ่านคำสั่งประจำตัว (brief.txt / BOT_BRIEF)
src/branding.js   ชื่อบอท คำแทนตัว อิโมจิ คำลงท้าย
src/db.js         SQLite: users / messages
src/media.js      อ่านรูป เสียง วิดีโอ ไฟล์ แล้วคืนเป็นข้อความ
src/time.js       เวลาโซนไทย
scripts/try-chat.js  คุยกับบอทใน Terminal
bin/backup-db.sh  ดึงไฟล์ฐานข้อมูลมาเก็บในเครื่อง (เก็บ 14 วัน)
```

ภาพรวมการทำงานแบบแผนภาพ: [WORKFLOW.md](WORKFLOW.md)

**หมายเหตุสำหรับคนดูแลระบบ:** บน Railway ถ้าต้องการอ่านเสียง/วิดีโอ ให้ตั้ง env `RAILPACK_DEPLOY_APT_PACKAGES=ffmpeg`

## ความเป็นส่วนตัว

บอทเก็บบทสนทนาและชื่อ LINE ของคนที่คุยด้วยลงฐานข้อมูลของผู้ติดตั้งเอง ไม่ได้ส่งให้ใครนอกจากผู้ให้บริการ AI ที่ใช้ตอบ — ควรแจ้งคนที่คุยด้วยว่ากำลังคุยกับบอทและมีการเก็บบันทึก

ใครถือ `ADMIN_KEY` ดาวน์โหลดไฟล์ฐานข้อมูล (บทสนทนาทั้งหมด) ได้ — ตั้งให้ยาวและอย่าแชร์
